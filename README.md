# Call-Center-Analysis-Dashboard-Power-BI-

☎️ Call Center Analysis Dashboard (Power BI)
📊 Overview
This project presents a Call Center Performance Dashboard built entirely using Power BI.
It provides key operational insights into agent activity, call resolution, customer satisfaction, and overall performance metrics.

🔧 Tools Used
Power BI: For data cleaning, modeling, and creating visuals

📁 CSV Dataset (Call logs, agent info, resolution data)

🧩 Key Insights Delivered
📞 Total Calls Handled

👨‍💼 Agent Performance

⏱️ Average Call Duration

✅ First Call Resolution Rate

😊 Customer Satisfaction (CSAT)

🔁 Repeat Calls vs Resolved

📆 Daily/Hourly Call Volume Trends

📈 Visuals & Features
KPI Tiles with dynamic filters

Line & Bar Charts for trends

Agent-wise comparison visuals

Slicers by date, department, issue type

Clean & interactive user interface
